Die Pro/Contra-Diskussion unter einem Statement, in zwei Spalten (auf schmalen Bildschirmen untereinander).

- Jede Spalte ist eine Fläche mit Rahmen `line` und Radius `radius-md`, weil sie wirklich zusammengehörige Einträge umschließt.
- Kopfzeile mit Wort und Zeichen: „✓ Pro“ auf `green-100` in `green-700`, „✗ Contra“ auf `earth-100` in `earth-700`. Grün und Rot sind fast gleich hell; die Unterscheidung tragen Wort, Zeichen und Spalte.
- Argumente als Zeilen mit Haarlinie, Schrift `body`. Unterargumente als Quiet-Link „2 replies“, der eine Ebene tiefer führt.
- Auf der tieferen Ebene steht das gewählte Argument groß oben, darüber ein Zurück-Link „Back to …“ in `sky-700`.
- Ersetzt die bisherigen Karten mit farbigem Rand links.
