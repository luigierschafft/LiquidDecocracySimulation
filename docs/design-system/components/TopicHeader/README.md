Der Kopf jeder Topic-Seite in fester Reihenfolge: Zurück, Titel, Beschreibung, Reiter, Zeitleiste.

- „← All topics“ als Link in `sky-700`, mindestens 44 px hoch.
- Titel im Stil `title` (Marcellus 30/36, mobil 26/32) direkt darunter: das Erste, was man liest.
- Beschreibung in `body-lg`, `ink-muted`, höchstens `measure-text` breit.
- Reiter Discussion, Proposals und Plan mit Anzahl statt eines Auswahlfelds. Der aktive Reiter ist `ink` mit 3 px Unterstrich in `gold-500`.
- Zeitleiste: 4 px hohe Linie in `line`, gefüllt in `gold-500`, daneben „8 days left“. Bei unbefristeten Topics nur der Text „Open, no end date“.
- Rechts oben bleibt Platz für die schwebenden Buttons „Sign in“ und das Menü.
