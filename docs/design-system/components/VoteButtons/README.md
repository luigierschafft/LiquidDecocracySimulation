Die vier Abstimmungsoptionen für einen Vorschlag, gleich breit nebeneinander (mobil 2 × 2).

- Jede Option trägt Wort und Zeichen: ✓ Approve, ○ Abstain, ✗ Disapprove, ✗✗ Strong no.
- Ruhezustand: weiß mit Rahmen `line-control`. Gewählt: Approve gefüllt `green-700`, Disapprove und Strong no gefüllt `earth-700` (weißer Text), Abstain `surface-sunk` mit Rahmen `ink-muted`.
- Strong no hat einen doppelt so starken Rahmen, weil es ein Veto-Gewicht hat.
- Darunter ein Satz, der die eigene Wahl bestätigt und sagt, bis wann man sie ändern kann.
- Folgedialoge (Begründung, Bedürfnisse bei Strong no) öffnen sich als Dialog mit `shadow-overlay`.
