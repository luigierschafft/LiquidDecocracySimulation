Drei Arten von Buttons; die Beschriftung nennt immer die Handlung.

- **Primary**: Fläche `gold-500`, Text `ink` (7,2:1), Hover `gold-300`. Höchstens einer pro Ansicht: die eine Sache, die man jetzt tun kann.
- **Secondary**: weiß, Rahmen `line-control`, Hover `surface-sunk`. Für gleichwertige Nebenwege wie „Sign in“ oder „Cancel“.
- **Quiet**: unterstrichener Text in `sky-700`. Für kleine Zusatzhandlungen wie „Add source“.
- Höhe mindestens 44 px, Radius `radius-sm`, Schrift `label`.
- Während einer Aktion: Text ändert sich in die Verlaufsform („Submitting…“), Button deaktiviert.
- Keine Symbole vor dem Text außer bei Pro/Contra (✓/✗). Kein „+“ und kein „→“.
