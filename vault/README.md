# Agora-Vault (Obsidian)

Dieser Ordner ist ein [Obsidian](https://obsidian.md)-Vault: die gemeinsame Wissensbasis für das Autopoietic Agora / Liquid Democracy Auroville. Alles ist normales Markdown, also auch direkt hier auf GitHub lesbar.

## Öffnen

1. Repo klonen (oder pullen).
2. In Obsidian: **Open folder as vault** → den Ordner `vault/` wählen.
3. Mit [[Home]] starten.

Für automatisches Sync mit GitHub eignet sich das Community-Plugin **Obsidian Git** (optional).

## Struktur

| Ordner | Inhalt |
|---|---|
| `00 Inbox` | Schnelle, unsortierte Notizen. Neue Notizen landen hier. |
| `10 Grundlagen` | Längere Hintergrund- und Recherchetexte |
| `20 Konzepte` | Kurze Notizen, eine Idee pro Notiz, stark verlinkt |
| `30 Designprinzipien` | Prinzipien für die Plattform |
| `40 Plattform` | Wie die App gebaut ist, Brücke zum Code |
| `50 Entscheidungen` | Entscheidungsprotokolle (was, wann, warum, Einwände) |
| `90 Vorlagen` | Vorlagen für neue Notizen |
| `99 Anhänge` | Bilder, PDFs |

## Regeln

- Verlinken mit `[[Notizname]]`. Lieber eine Notiz zu viel verlinken als zu wenig.
- Jede Notiz hat oben Properties (`tags`, `status`).
- Persönliche Obsidian-Einstellungen (`workspace.json`) werden nicht committet.
